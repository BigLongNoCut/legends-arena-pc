# Легенды Арены — версия для ПК

2D MOBA 5×5 против ботов.

## ⬇️ [Скачать LegendsArena.exe](https://github.com/BigLongNoCut/legends-arena-pc/releases/latest/download/LegendsArena.exe)

Windows 10/11, 64-бит. Установка не нужна: скачайте и запустите.

- Если Windows покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае» (файл без цифровой подписи).
- F11 — полноэкранный режим.

Все версии — на странице [Releases](https://github.com/BigLongNoCut/legends-arena-pc/releases).
